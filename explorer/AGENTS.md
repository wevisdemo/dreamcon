# Dreamcon Explorer

Applies on top of the root `AGENTS.md`. Paths are relative to this package.

## Guideline

- [TanStack Start](https://tanstack.com/start) with file-based routing: one file per route in `src/routes/`, `__root.tsx` holds the HTML shell and `<head>`
- `src/routeTree.gen.ts` is generated by the Vite plugin on `dev`/`build`; commit it, never edit it by hand
- The site is statically prerendered at build time (`prerender` in `vite.config.ts`) and deployed as plain files from `dist/client/`; there is no server at runtime, so no server functions or request-time data. Routes with path params are only prerendered when linked from another page
- Route components render at build time too: keep browser-only APIs (`window`, `localStorage`) inside effects or event handlers
- No e2e tests: the root `pnpm test` doesn't cover this package, so verify changes with `pnpm build`
